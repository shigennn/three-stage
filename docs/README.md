# THREE Stage ドキュメント

THREE Stage は、Web サイトや Web アプリケーションに組み込む 3D シーンを、three.js で作成するデスクトップアプリケーションである。

| ドキュメント | 内容 |
|---|---|
| [getting-started.md](getting-started.md) | 動作環境、インストール、プロジェクトの作成と構成、基本的な作業手順、コマンド一覧 |
| [studio.md](studio.md) | エディタの画面構成と操作、Scene と Timeline、ショートカット |
| [scripting.md](scripting.md) | コンポーネント、シェーダー、ポストエフェクト、Trigger、カメラの動き、2D UI、モックデータの記述方法と、ランタイムの API |
| [scene-format.md](scene-format.md) | シーン定義ファイルの形式、Publish とパッケージの出力、Web アプリケーションへの組み込み方法 |
| [performance.md](performance.md) | 性能の目標と上限、計測方法、最適化の手法 |
| [packages/studio/tools/README.md](../packages/studio/tools/README.md) | 計測ツール（`three-stage shot`、`measure`、`soak`）の引数と出力 |
